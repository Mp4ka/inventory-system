# Приёмочный чек-лист (Спринт 3)

Проверка сценариев поиска, изменения и удаления.

## Поиск
- [ ] Поиск по полному номеру (INV-001) находит запись.
- [ ] Поиск по части номера (001) находит запись.
- [ ] Поиск по кабинету (301) выводит все записи кабинета.
- [ ] Поиск по неизвестному номеру выводит «Не найдено».
- [ ] Пустые поля поиска не вызывают ошибок и не завершают программу аварийно.

## Изменение
- [ ] Можно изменить кабинет и/или состояние.
- [ ] Недопустимое состояние (например, «сломано») отклоняется.
- [ ] Изменение на уже занятый номер отклоняется.
- [ ] Изменение несуществующего номера даёт понятное сообщение.

## Удаление
- [ ] Удаление выполняется только после ответа «да».
- [ ] Ответ «нет» отменяет удаление без изменений.
- [ ] Удаление несуществующего номера обрабатывается корректно.
