# Финальная сводка проекта

## Что сделано

Консольная «Система учёта инвентаря компьютерных классов» на Python:
просмотр, добавление, изменение, удаление и поиск оборудования; хранение в JSON.

## Реализованные функции

- Просмотр списка оборудования: карточки в рамке, тип и состояние подсвечены цветом.
- Добавление с проверкой полей и уникальности номера; при пустом номере — автогенерация.
- Поиск по номеру/кабинету/типу/состоянию (частичное совпадение, без учёта регистра).
- Изменение записи с проверкой состояния; нельзя стереть обязательные поля.
- Удаление с подтверждением.
- Автосохранение в `data/inventory.json`; обработка отсутствия и повреждения файла.
- Ошибки ввода выводятся сразу и предлагают исправить (повторный ввод поля / повтор операции).
- 33 автотеста, Dockerfile, README, User Stories, инструкция пользователя, журнал спринтов.

## Демонстрационный сценарий

1. Показать оборудование.
2. Добавить запись (пустое поле — ошибка и повторный ввод).
3. Найти по кабинету.
4. Изменить состояние.
5. Выйти и снова зайти — изменения на месте.
6. Удалить с подтверждением.
