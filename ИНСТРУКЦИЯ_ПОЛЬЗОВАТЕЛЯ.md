# Инструкция пользователя

## Что это

Консольное приложение «Система учёта инвентаря компьютерных классов» ведёт реестр
оборудования колледжа: просмотр, добавление, изменение, удаление и поиск записей.

## Как запустить

1. Установите Python 3.11 или новее.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите: `python main.py`.

## Меню

| Пункт | Действие |
|-------|----------|
| 1 | Показать оборудование |
| 2 | Добавить запись |
| 3 | Изменить запись |
| 4 | Удалить запись (с подтверждением) |
| 5 | Поиск (по номеру, кабинету, типу, состоянию) |
| 0 | Сохранить и выйти |

## Как добавить запись

Выберите «2» и заполните поля: инвентарный номер (можно оставить пустым — сгенерируется
автоматически), тип, наименование, кабинет, состояние (исправно / требует ремонта / списано).
Дата поступления и ответственное лицо — необязательные поля.

## Как найти запись

Выберите «5» и укажите любое сочетание полей. Поиск работает по частичному совпадению
без учёта регистра (например, «001» найдёт INV-001). Пустые поля не учитываются.

## Как изменить запись

Выберите «3», укажите номер, затем новые значения (пустое поле — оставить прежним).
Недопустимое состояние или пустое обязательное поле будут отклонены.

## Как удалить запись

Выберите «4», укажите номер и подтвердите («да»). Ответ «нет» отменит удаление.

## Где хранятся данные

Файл `data/inventory.json`. Данные сохраняются автоматически после каждого изменения.

## Известные ограничения

- Один пользователь за раз; нет авторизации и разграничения прав.
- Хранение в одном JSON-файле; нет одновременной работы из нескольких процессов.
- Только текстовый интерфейс.
- Docker-запуск — дополнительный вариант (при наличии Docker).
